# macOS Native UI

You are now in macOS native UI mode. Load the `macos-native-ui` skill for full expertise.

## What I Can Help With

- **Design review**: Evaluate SwiftUI views against Apple HIG and Forma design system
- **Implementation guidance**: macOS-specific SwiftUI patterns, NavigationSplitView, toolbars, keyboard shortcuts
- **AppKit bridging**: When and how to use NSViewRepresentable for native behaviors
- **Forma tokens**: Correct usage of FormaColors, FormaTypography, FormaSpacing, FormaRadius, FormaAnimation
- **Accessibility audit**: VoiceOver, keyboard navigation, reduce motion/transparency support
- **Anti-pattern detection**: Flag iOS-isms, missing platform conventions, custom controls that should be native

## Usage

- `/macos-native-ui` — Start interactive guidance session
- `/macos-native-ui review SomeView.swift` — Review a specific file for macOS UI quality
- `/macos-native-ui tokens` — Quick reference for Forma design system tokens

Ask your question or describe what you're building, and I'll provide platform-native guidance.
