## Full Description (Press Release Format)

### Forma Launches: The File Organizer That Respects Your Decisions

**Remote, February 2026** — Forma, a new macOS utility, offers a fresh approach to file organization: propose first, act second.

While automation tools like Hazel require scripting expertise and AI organizers like Sparkle act autonomously, Forma occupies the middle ground. Users create declarative rules through a visual interface—"Move screenshots older than 7 days to Archive"—and Forma proposes destinations for matching files. Nothing moves until the user approves.

"People treat their file system like a bank vault," says the Forma team. "They need an organizer they can trust. Forma earns that trust by showing exactly what it plans to do, waiting for approval, and making every action reversible."

**Key Features:**
- **Preview Queue**: See every proposed change before execution
- **Full Undo History**: Complete action log with one-click rollback
- **Rules That Read Like Sentences**: Readable condition-based rules without scripting
- **100% Local**: On-device processing; files never leave your Mac
- **Native macOS**: Fast and lightweight — built natively for macOS

## Feature Highlights

### 1. Preview Before Commit
Every proposed file move appears in a queue. See the source, destination, and reasoning before anything happens. Approve individually or in batches.

### 2. Full Action History
Every action Forma takes is recorded. Undo any single action or roll back multiple changes. Experiment without fear.

### 3. Declarative Rules
Create organization logic in plain language. "Move PDFs from Downloads to Documents/Invoices when filename contains 'invoice'." No scripting required.

### 4. Pattern Matching
Forma infers structure from file extensions, naming patterns, dates, and sizes. Suggestions are inspectable—see why Forma proposes what it does.

### 5. Ready-Made Templates
Pre-loaded with 30+ rules for common scenarios: screenshots, downloads, documents, project files. Start organizing immediately.

### 6. Native and Private
Built exclusively for macOS using native file APIs. All processing happens on-device. No cloud, no telemetry on file contents.
