# Forma Quick Action DialKit Prototype

This prototype explores a quicker, more tactile quick-action surface for Forma using React, Vite, `motion`, and `dialkit`.

Focus areas:

- richer document cards for common file types
- radial quick actions for organize flows
- translating current Forma visual tokens into a browser prototype

Run locally:

```bash
npm install
npm run dev
```

Build a static preview:

```bash
npm run build
```
